# Validation Matrix

Every row is mandatory. Evidence is a future proof obligation, not a checked
box. The development coordinator alone qualifies fresh evidence against the
immutable candidate, integration, and release identities.

| Requirement | Claim | Acceptance criteria | Validation | Final evidence contract |
| --- | --- | --- | --- | --- |
| `REQ-ADVICE` | The owner receives explainable calendar-month category position and a Yes, Caution, or No answer for a described purchase with before/after remaining, data freshness, pending impact, and category confidence. | For deterministic fixture transactions, the answer correctly includes only budget-eligible spend, handles refund and excluded activity, and returns Caution or a clarification instead of false certainty for stale, ambiguous, pending, or incomplete inputs. | `VALIDATE-ADVICE` / playwright | `EVIDENCE-ADVICE` |
| `REQ-CATEGORIZATION` | The product classifies incoming transactions locally with rules and supervised evidence, accepts only high-confidence bridged predictions, and records durable owner corrections through a review queue. | An owner can review an uncertain classification, see confidence and reasons, correct it once, and observe an auditable rule without an unreviewed prediction changing a category aggregate. | `VALIDATE-CATEGORIZATION` / playwright | `EVIDENCE-CATEGORIZATION` |
| `REQ-FOUNDATION` | The runtime persists a private local ledger and redacted telemetry, keeps secrets out of SQLite and logs, and permits only owner-authorized local operations. | A fresh copied database proves encrypted-secret separation, local authorization, idempotent scheduler control, redacted telemetry, and recovery without affecting the source fixture. | `VALIDATE-FOUNDATION` / database-copy | `EVIDENCE-FOUNDATION` |
| `REQ-REMOTE-VOICE` | The owner can invoke the same local budget question through Codex Remote with typed input or a client-provided transcript and can use an accessible responsive voice-entry interface with transcript confirmation. | The Codex command and responsive web flow return the same calculation without elevated authority, and the voice flow provides visible recording, failure, transcript-edit, and submit states without uploading audio by default. | `VALIDATE-REMOTE-VOICE` / playwright | `EVIDENCE-REMOTE-VOICE` |
| `REQ-SYNC` | The owner authorizes a read-only Plaid account link and receives cursor-deduplicated posted and pending transaction snapshots through a daily local schedule or explicit refresh. | A simulated Link and cursor sync create one atomic immutable snapshot, preserve the prior snapshot on Link or network failure, expose its as-of time, and never issue a money-moving API call. | `VALIDATE-SYNC` / playwright | `EVIDENCE-SYNC` |
| `REQ-WORKBOOK` | The owner previews and explicitly imports the source workbook as an immutable category budget and labeled-history dataset with only the approved category bridge. | The owner can confirm a preview that preserves workbook bytes, evaluates every budget target, records the source hash and bridge, and rejects malformed or ambiguous inputs without replacing the prior plan. | `VALIDATE-WORKBOOK` / playwright | `EVIDENCE-WORKBOOK` |
